# Third-party notices

Parental OpControl is distributed by OpControl IT Solutions. The authoritative
third-party list and the full license texts are **generated at build time** from
the real NuGet dependency graph and the bundled fonts:

- `tools/generate-third-party-credits.cs` reads the Client, Helper and Luna
  `project.assets.json` files, the package `.nuspec`/license files and the font
  folders.
- The kid view's **About** screen embeds the Luna package list
  (`third-party-credits.json`) generated by the same tool.
- The Windows installer ships `legal/THIRD-PARTY-NOTICES.md` (the generated
  list plus full license texts), `legal/LICENSE`, and the SIL Open Font License
  texts in `legal/fonts`.

The generated notices cover Avalonia, LiveMarkdown.Avalonia,
LiveMarkdown.Avalonia.Math, the Fredoka and Nunito fonts (SIL OFL 1.1), the
helper and client packages, and every transitive runtime package that is
bundled. Do not hand-edit a package list here: run the build so the list is
regenerated from the actual dependencies.
