Windows DWM does not expose the transparent Luna window to screen capture (CopyFromScreen returns the wallpaper and PrintWindow returns black). The real X1 was checked with the native region API instead: at 150% the open chat window is a COMPLEXREGION with box 0,0,779,899, i.e. a 22 DIP rounded window, and the rectangular Blob is hidden at full chat. The green frame therefore cannot render. The raw check was:

moon 780x900 at 0,0 hwnd=1246036
chat 780x900 at 0,0 hwnd=1246036 rgn_type=3 rgn_box=0,0,779,899 box_ok=3

A screenshot of the Luna chat window itself could not be captured remotely; the kid view 150% screenshots above are real X1 captures with demo data in the docs for privacy.
